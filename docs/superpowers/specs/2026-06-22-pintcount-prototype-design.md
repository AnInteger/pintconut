## 0. 文档目的与范围

本文档把 PRD 翻译成**可执行的 UI 原型规格**：视觉语言、设计令牌、组件库、每一屏的布局与状态、失败兜底、动效与文案规范。

**产出两类资产**：

1. 本规格文档（自描述，mockup 丢失也能独立读懂）。
2. 配套 HTML mockup（见 §13），仅作可视化参考，存放于 gitignore 的 brainstorm 会话目录，**不进版本库**；如需留存应另行拷贝。

**范围声明**：只覆盖消费者 APP（PRD F1–F5）。仓库内标注 / 训练工具不在本设计范围内（见 PRD §12）。

## 1. 设计目标与原则

| 原则 | 说明 |
|------|------|
| **魔法流优先** | 默认全自动，最少步骤。失败时才出手动逃生舱，且不破坏魔法感（PRD §4.2.4 / §4.3）。 |
| **零学习成本** | 首页即入口，开 App 即用。 |
| **防翻车的安心感** | 视觉上可信、稳定，结果清晰无歧义。 |
| **平实，不抖机灵** | 文案与视觉都避免"AI 口号感"和对仗押韵；工具感优先，不堆设计腔。 |
| **产品即素材** | 拼豆 / 马赛克 / 色盘本身就是品牌素材，用作纹理与缩略图，而非装饰。 |

## 2. 视觉语言

**调性：鲜亮活泼，但克制。** 选定方向（代号 C）：紫→粉品牌渐变作主色，暖白底，深墨色文字，大量留白。年轻、社交友好（契合小红书 / 抖音），但不花哨——用留白与层级压住饱和度。

**取舍记录**：

- 候选 A「暖手作」偏可爱手作、候选 B「极简利落」偏工具克制，均被淘汰；C 兼顾社交感与工具可信。
- 全程**不使用 emoji**（产品约定）。图标用纯 CSS 几何形。
- 结果页**不使用边框线**；用底色面板、留白、软阴影分组。

## 4. 组件库

### 4.1 按钮

| 组件 | 规格 |
|------|------|
| **主按钮（Primary）** | 高 54，`r/btn`，品牌渐变底，白字 17/800，`sh/cta`。例：`Count`。 |
| **深色按钮（Dark）** | 同尺寸，`ink` 底。 |
| **次级文字按钮** | 高 44，`muted` 字 15/700，居中；以极浅 `line` 下划线收边。 |
| **胶囊（Pill）** | 高 ~32，`r/pill`，渐变或纯色底，14/800。用于结论（如「3 处错误」）。 |

### 4.2 错误标记（核心）

| 标记 | 视觉 | 含义 |
|------|------|------|
| **编号红框** | `3px solid #EF4444`，`r 7`，外发光 `0 0 0 3px rgba(239,68,68,.22)`；右上角挂编号圆 `22px`（白描边 `2px solid bg/app`） | 图上每一处错误的位置 + 序号 |
| **颜色错** | 实心红圆点 `16px` | 清单分类 |
| **空缺** | 红色空心方框（`2.5px solid`，小圆角） + 图上用**虚线**红框 | 该有豆没放 |
| **多余** | 红色 `+` 号 | 图纸要求空、实际放了 |

> 图上红框编号 ①②③ 与清单序号一一对应：图 = 位置，清单 = 详情，二者是索引关系，**不是重复**。

### 4.3 卡片

- **作品卡（Recent / Gallery）**：宽 150，圆角 18，**缩略图即为该作品的豆子马赛克**（不是纯色块），左下角结果徽章（「3 错」红 / 「通过」绿），下方标题「名称 · 尺寸」+ 时间。
- **软底面板**：`bg/soft`，`r/card 20`，内 padding 16，**无边框**；用于错误索引等成组信息，组内用留白分隔，无分割线。
- **统计单元**：数字（`display` 22/900）+ 标签（`caption`），三列并排（MVP 结果页默认**不展示**，避免与清单重复）。

### 4.4 栏

- **Status bar**：46，左时间 16/700，右电池形（纯 CSS）。
- **导航栏**：52，左返回 chevron + 标题 17/800，右操作（文字 15/800 `brand`）。**无下边框**。
- **Tab bar**：`line` 上分割，高 60 + 安全区；三栏 首页 / 作品库 / 设置；图标 24（CSS 几何形），选中态图标渐变 + 文字 `brand`。
- **底部操作栏**：`sh/lift` 上浮（**无上边框**），次级文字按钮 + 主按钮。

### 4.5 纹理

- **豆子马赛克（beads）**：多层 `radial-gradient` 叠加 + `background-position` 错位，形成多色圆豆网格。用于**成品图、图纸解析预览、作品缩略图**——产品真实素材，非装饰。
- **流动马赛克字（mosaic，待重设计）**：单色 `#7C3AED`、6px 颗粒、慢速 10s 流动，`background-clip:text`。当前为占位实现，**留待用户重设计**（见 §14）。

## 5. 信息架构与导航

极简三屏 + 一次性魔法流（沿用 PRD §5）：

```
[ 首页 ]            [ 作品库 ]           [ 设置 ]
 拍照入口            本地作品列表          色盘品牌选择
 Count CTA          每作品→成品+历次检测   关于 / 隐私
 最近作品(横滑)       重扫复核
```

底部 Tab 常驻三栏。魔法流（图纸→拍照→结果）为模态全屏流程，完成后回到原 Tab。

---

## 6. 核心魔法流

```
首页(Count) → ① 选图纸(自动解析) → ② 拍成品照(自动定位) → ③ 检测中(流水线) → ④ 差异结果 → ⑤ 分享卡片
                                          ↑失败兜底：重拍引导
```

每步详见 §7。重扫路径：作品库 → 作品 → 重扫（跳过图纸，直接 ②）。

## 7. 屏幕规格

> 每屏列出：布局 / 元素 / 状态。状态名加粗。

### 7.1 首页（Home）

- **布局**：Status → 品牌 lockup → Hero（display 标题 + 一句功能说明）→ 主按钮 `Count` → 最近作品（横滑）→ Tab bar。
- **元素**：品牌标记（渐变方块 28）+ `Pintcount`；Hero 标题「拼豆质检」+ 副文案；`Count` 主按钮；「最近作品」标签 + 「全部」；作品横滑卡。
- **状态**：
  - **有作品**：展示横滑卡（豆子马赛克缩略图 + 徽章）。
  - **空状态（首次使用）**：作品区替换为引导卡——一句话说明 + 一个引导动作（指向 Count）。

### 7.2 选图纸（Blueprint）

- **布局**：导航栏「图纸」+ 右上「换一张」→ **已解析图纸为主角**：豆子马赛克大图 + 左下角尺寸徽章（如「29 × 29」）→ 元信息行「N 种颜色 · 品牌色盘」→ 色板色块条 → 主按钮「用这张图纸去拍照」。
- **元素**：图纸马赛克预览、尺寸、颜色数、色盘名、色块条、主按钮。
- **状态**：
  - **解析中**：马赛克上叠加载指示，副信息「识别 29 × 29 · Perler」。
  - **解析成功**：如上布局。
  - **置信度低**：温和提示重选 / 重截（不强制手动）。
  - **反复失败（逃生舱）**：提供「手动框选网格区」作为唯一手动干预。
  - **入口（换一张）**：底部表单四选一——相册导入 / 拍照图纸 / 分享扩展 / 文件。

### 7.3 拍成品照（Capture）

- **布局**：全屏深色取景器 → 自动识别拼板（四角粉色角标 + 「已锁定拼板」胶囊）→ 底部快门（渐变圆）+ 「从相册选」+ 「翻转」。
- **元素**：取景器、角标、锁定胶囊、快门、相册 / 翻转。
- **状态**：
  - **锁定中**：角标动画寻框。
  - **已锁定**：角标定格 + 胶囊。
  - **识别困难**：失败兜底——「重拍 + 打光 / 角度建议」引导，**不强制手动校正**。

### 7.4 检测中（Processing）

- **布局**：居中加载环 → 「正在逐格比对」→ 流水线步骤清单（拼板定位 / 透视校正 / 网格提取 / LAB 颜色对比），完成项绿点、进行项品牌色空心环。
- **状态**：步骤逐项完成；**异常超时** → 提示重试。

### 7.5 差异结果（Results）

- **布局**：导航栏「检测结果」+ 右「重扫」→ 结果图（豆子马赛克 + 编号红框）→ 结论行（渐变胶囊「N 处错误」+ 一行小结「a 颜色错 · b 空缺」）→ 错误索引软底面板（编号 + 分类 + 格位 + 详情）→ 底部操作（「保存」次级 + 「分享」主按钮）。
- **元素**：编号红框、结论胶囊、小结、错误索引、保存 / 分享。
- **状态**：
  - **有错（不通过）**：如上，红框 + 清单。
  - **通过（0 错）**：结论胶囊变 `success` 绿「质检通过」，图为净图（无红框），主按钮「分享」（庆祝感来自颜色与文案克制，不靠动效喧宾夺主）。
  - **检测失败**：图位替换为失败兜底卡——「没认出来」+ 重拍 / 重选图纸引导。

### 7.6 分享卡片（Share）

- **布局**：卡片预览（成品缩略图 + 结论角标 + 「质检完成」+ 尺寸 / 色盘 + 「用 Pintcount 一键质检」水印）→ 「分享到」→ 系统分享入口行（小红书 / 微信 / 保存，仅占位，实际走系统 Share Sheet）。
- **元素**：卡片、水印、分享入口。
- **状态**：MVP 固定单模板（多模板 v2）。

### 7.7 作品库（Gallery）

- **布局**：导航栏「作品库」→ 作品列表（作品卡纵向或网格）→ 点进作品详情（成品 + 历次检测 + 重扫）。
- **状态**：**空状态**——引导首次 Count。

### 7.8 设置（Settings）

- **布局**：分组列表——色盘品牌（Perler / Hama / Artkal，首次选择后默认沿用）、关于、隐私说明。
- **状态**：选择态高亮。

## 8. 关键状态与失败兜底（统一原则）

遵循 PRD §4.2.4 / §4.3 的「魔法优先，反复失败才出手动逃生舱」：

1. 默认全自动，不让用户手动调参。
2. 置信度低 → 温和提示重试（重选 / 重拍 / 重截），不弹手动工具。
3. 反复失败 → 才提供**唯一一项**手动逃生舱（图纸：手动框选网格；拍照：重拍引导）。
4. 全程避免死循环与无助感。

## 9. 动效

- **克制为主**：过渡用系统标准时长（~250ms ease），不堆动效。
- **流动马赛克**：仅 hero / 品牌处，单色慢速（10s），作品牌印记。
- **加载**：旋转环 + 步骤推进，给确定性反馈。
- **红框出现**：结果出来时红框依次淡入（轻微，可关）。

## 10. 文案规范（去「AI 味」）

**原则**：平实、工具感、不口号化；不对仗、不押韵、不堆形容词；必要才说。

| 场景 | 避免 | 采用 |
|------|------|------|
| 主按钮 | 「开始质检」「一键拍照质检」 | `Count` |
| 结果结论 | 「发现 N 处错误」「质检满分」 | `N 处错误` / `质检通过` |
| 分享 | 「生成分享卡片」 | `分享` |
| 保存 | 「保存到作品库」 | `保存` |
| 提示 | 「别离开，马上就好」「把整块拍进来」 | （删去，或仅留状态：`正在逐格比对`、`已锁定拼板`） |

> 文案最终稿由用户重设计时定稿；本表为方向约束。

## 11. 无障碍

- 所有可点目标 ≥ 44pt。
- 文字与底色对比度满足 WCAG AA（`ink` on `bg/app` 达标；`muted` 仅用于次要信息）。
- 错误不止靠颜色：图上有编号红框、清单有文字与分类图标，色弱可读。

## 15. 关键决策记录

| # | 决策点 | 选择 | 理由 |
|---|--------|------|------|
| 1 | 视觉调性 | **C 鲜亮活泼（克制版）** | 兼顾社交感与工具可信；A 太可爱、B 太冷 |
| 2 | 图标方案 | **纯 CSS 几何形，禁 emoji** | 产品约定；可控、轻量 |
| 3 | 基准设备 | **iPhone 390pt** | 最常见宽度，按真实尺寸设计保协调 |
| 4 | 首页主入口 | **单按钮 `Count`** | 流程需先选图纸再拍照，原双按钮并列矛盾 |
| 5 | 最近作品 | **横滑 + 豆子马赛克缩略图** | 作品即素材；横滑更移动原生 |
| 6 | 选图纸主角 | **已解析图纸马赛克大图** | 直接体现"解析为豆子+色盘"的产品价值 |
| 7 | 结果页分组 | **去边框，软底面板 + 编号索引** | 避免重复、去边框线、图与清单为索引关系 |
| 8 | 文案 | **平实工具感，去 AI 口号** | 用户明确反感口号化文案 |
| 9 | 马赛克字效 | **单色慢速（占位）** | 用户嫌彩色版太花，将自行重设计 |
