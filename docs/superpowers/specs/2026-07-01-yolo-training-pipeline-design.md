# YOLO 豆子检测训练 Pipeline 改进（方案 B）

> 日期: 2026-07-01 | 状态: 设计待审 | 关联: `bead_train.py`, `bead_validate.py`, `bead_annotate_mpl.py`

## 1. 背景

### 现状
- 标注数据：3 张图 237 instances（1.jpg 220 颗小豆 + IMG_6112 42 + NYQC4978 12）
- 已训 YOLOv8n（imgsz 1024, epochs 100, CPU）
- 结果：val(NYQC4978 大豆子) R=0.81；1.jpg 小豆子 SAHI 切图 0→319（中等质量）；IMG_6093（深红酒红+阴影）**0 检出**（泛化失败）

### 文章学习（Ultralytics 最佳实践）暴露的差距
- **Partial labeling will not work**：1.jpg 只标了 220/上千颗（部分标），违反"必须全标"——这是漏检根源
- **多样性不足**：3 张图颜色/光照/角度单一 → 泛化差（IMG_6093 检不出）
- **数据量**：3 张 vs 推荐 ≥1500 图/类、≥10000 instances/类
- **训练设置**：imgsz 1024（小豆子需 1280）、epochs 100（推荐 300）、无背景图
- **结论：数据（完整性+多样性）是天花板，不是模型/方法**

## 2. 目标 / 非目标

**目标（方案 B：中等投入）**
- 标注规范文档化 + 工具加 YOLO 预填（主动学习），减标注痛
- 标 10-15 张多样图（全标），让模型泛化到新场景（颜色/光照/角度）
- 训练设置优化（imgsz 1280 / epochs 300 / 背景图），榨干性能
- 独立 val，可信指标

**非目标（YAGNI）**
- 生产级（100+ 张，方案 C，本期不做）
- 改传统算法（已验证极限，YOLO 是正路）
- 多类别（单类 bead 足够）

## 3. 设计

### 3.1 标注规范（写进文档，标的时候遵循）
- **紧贴豆缘**：外接正方形，4 边切豆缘，不含背景不切豆
- **全标**：每张图所有豆子都标（不漏），违反则模型学不全
- **全局一致**：所有豆子同一标准（紧贴），±2-3px 容忍，别系统偏大/小
- **彩色原图**：颜色是关键特征（彩色豆 vs 白板）
- **放大标注**：放大镜看清豆缘再点

### 3.2 标注工具增强：YOLO 预填（主动学习核心）
- 打开图时（或按 `f` 键）用当前 `best.pt` + SAHI（小豆子图）预填检测框
- 用户只需**补漏 + 删误 + 修不准**（比从头点快很多）
- 每标几张重训 → 模型变好 → 预填更准 → 越标越快（主动学习循环）
- 复用现有 `bead_annotate_mpl.py`（纯手动已有，加预填功能）
- ⚠️ 初期 v2 模型不准（过拟合），预填有误检/漏检，标几轮后改善

### 3.3 数据多样性策略（10-15 张，有目的扩）
按优先级覆盖（每张全标）：
1. **颜色**（最关键，解决 IMG_6093 问题）：红/蓝/黄/黑/白/混色板
2. **光照**：顺光/逆光/阴影/室内外
3. **尺度**：近拍（大豆子，整图 YOLO）/ 远景（小豆子，SAHI）—— 决定推理方式
4. **角度**：正视/倾斜
5. **遮挡**：有无手/工具

留 **2-3 张独立 val**（绝不重叠 train，类别分布相似）。

### 3.4 训练设置（基于文章最佳实践）
- **imgsz 1280**（小豆子清晰；推理用同 imgsz）
- **epochs 300**（patience 50 早停）
- **背景图 0-10%**（拍几张空板子/桌面，无豆子，降误检 FP）
- 默认增强（mosaic 等）+ **cos-lr**
- yolov8n 预训练权重
- CPU 训练（慢，后台跑；15 张 300 epochs 估 30-60 分钟）

### 3.5 验证流程
- **val 指标** P/R/mAP（独立 val，可信，不再 val=train 虚高）
- `bead_validate` 推理可视化（各图检测框）
- **SAHI 推理**（小豆子图，切图）
- 对比 train/val 指标看过拟合（train 升 val 降 = 过拟合）

## 5. 风险与对策
- **YOLO 预填初期不准**（v2 过拟合）：预填框可删可改，标几轮后模型变好；提供"不预填"模式（直接纯手动）
- **CPU 训练慢**：后台跑，patience 早停
- **10-15 张仍偏少**：比 3 张好很多，泛化应明显改善；要生产级再扩到方案 C
- **小豆子（18px）即使 imgsz 1280 也吃力**：SAHI 切图推理兜底
