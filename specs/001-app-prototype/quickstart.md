# Quickstart — Pintcount 原型走查

原型为纯静态 HTML，无构建 / 无依赖。走查 = 浏览器打开 + 按清单核对。

## 前置
- 现代桌面浏览器（Chrome / Safari / Edge）。

## 打开
直接用浏览器打开 `docs/mockups/index.html`（导航枢纽），按分组点进各屏；或直接打开任意 `*.html` 单屏。

## 核心走查路径（ happy path ）
`index → home → blueprint → capture → processing → results → share`。
- 首页点 `Count` → 选图纸 → 拍照 → 检测中 → 结果 → 分享，能完整理解「拍一张 → 对照图纸 → 标出错豆 → 分享」。

## 验收清单（逐项对照 spec FR / SC）
- [ ] **核心六屏**齐（首页 / 选图纸 / 拍照 / 检测中 / 结果 / 分享）。
- [ ] 选图纸屏有**备豆统计**（各色数量）+ **可选色盘**（FR-002）。
- [ ] 结果屏**多色标记**三类可区分：红=颜色错、蓝=空缺、橙=多余；编号 + 字形并存（FR-003 / SC-005）。
- [ ] 结果**通过态**（0 错 → 绿「质检通过」，净图）存在（FR-003）。
- [ ] 全程**无手动逃生舱**：低置信度 / 不支持 / 检测失败三帧只有重试 / 提示，无手动校正工具（FR-004）。
- [ ] 结果页**无「保存」按钮**（自动保存），底栏只有重扫 / 分享（FR-005）。
- [ ] 含**首启权限**帧（开 App 申请相机 / 相册）（FR-006）。
- [ ] 检测中页用**用户语言**，无 CV / 流水线术语（FR-008）。
- [ ] 视觉与既有 `docs/mockups/` 风格一致（品牌渐变 / 暖白 / 无 emoji / 去边框结果页）（FR-007 / SC-003）。
- [ ] index 可导航到每一屏 / 态（FR-009 / SC-004）。

## 预期结果
- 评审者可在 ≤5 分钟内沿 index 走通完整魔法流（SC-001）。
- 每屏内容可与 v1.4 PRD 逐项核对，无遗漏（SC-002）。

## 无运行 / 测试命令
静态资源，无 `npm` / `pytest` 等。如需本地起服务便于手机预览：`python -m http.server` 后访问 `http://localhost:8000/docs/mockups/`（可选）。
