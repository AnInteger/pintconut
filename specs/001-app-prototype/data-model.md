## 设计令牌（styles.css 承载，复用 2026-06-22 §3）

## 逐屏内容规格

### 1. index.html — 导航枢纽
卡片网格，按分组链接到各 frame：**核心魔法流**（home→blueprint→capture→processing→results→results-pass→share，标注建议走查顺序）、**作品库/设置**、**边界态**。顶部品牌 lockup + 一句说明「基于 v1.4 PRD 的原型，点击进入各屏」。

### 2. home.html — 首页
Status → 品牌 lockup（渐变方块 28 + `Pintcount`）→ hero（`拼豆质检` display + 副文案「熨烫之前，拍一张对照图纸，标出错豆。」）→ **主按钮 `Count`**（渐变 + chevron）→「最近作品」label +「全部」→ 作品横滑卡（豆子马赛克缩略图 + 结果徽章「3 错 / 通过」+ 名称·尺寸 + 时间）→ tab bar（首页选中、作品库、设置）。

### 3. blueprint.html — 选图纸（解析成功）
导航栏「图纸」+ 右「换一张」→ **已解析图纸马赛克大图** + 左下尺寸徽章「29 × 29」→ 元信息行「N 种颜色」+ **可选色盘**（胶囊组，Perler 选中）→ **备豆统计**（软底面板：每行 颜色色块 + 名称 + 数量，如「■ 草莓红 ×42」）→ 色块条 → 主按钮「用这张图纸去拍照」。

### 4. capture.html — 拍照
全屏深色取景器 → 四角粉色角标 + 胶囊「已锁定拼板」→ 底部快门（渐变圆）+「从相册选」+「翻转」。

### 5. processing.html — 检测中
居中加载环 →「正在逐格比对」→ **用户语言步骤**：对齐拼板 / 读取每格 / 比对颜色（完成项绿点、进行项品牌色空心环）。**不出现**「透视校正 / LAB / 网格提取」等术语。

### 6. results.html — 结果（有错）
导航「检测结果」+ 右「重扫」→ 成品图（豆子马赛克）+ **多色编号标记**：① ② 红=颜色错、③ 蓝=空缺、④ 橙=多余（各带编号圆 + 字形）→ 结论胶囊「4 处错误」+ 小结「2 颜色错 · 1 空缺 · 1 多余」→ 错误索引软底面板（编号 + 分类色点 + 格位 + 详情「应为 A · 实为 B」）→ 底栏：**无「保存」按钮**（自动保存），「重扫」次级 + 「分享」主。

### 7. results-pass.html — 结果（通过 0 错）
结论胶囊 `success` 绿「质检通过」→ 净图（无标记）→ 底栏「分享」主按钮（庆祝感来自颜色与文案克制）。

### 8. share.html — 分享卡片
卡片预览（成品缩略 + 结论角标「质检通过 / N 处错误」+「质检完成」+ 尺寸 / 色盘 + **「用 Pintcount 一键质检」水印**）→「分享到」→ 系统分享入口行（小红书 / 微信 / 保存，占位）。

### 9. gallery.html — 作品库列表
导航「作品库」→ 作品卡（豆子马赛克缩略 + 结果徽章 + 名称·尺寸 + 时间）纵向或网格 → tab bar（作品库选中）。体现**自动保存**（已完成检测自动在此）。

### 10. gallery-detail.html — 作品详情
成品照 + 历次检测记录（时间线：每次检测的错误数 / 通过 + 时间）+「重扫」按钮（跳过图纸，直接进拍照——图纸已随作品保留）。

### 11. settings.html — 设置
分组列表：色盘品牌（Perler / Hama / Artkal，选中态高亮）→ 关于 → 隐私说明 → tab bar（设置选中）。

### 12. first-run.html — 首启权限
开 App → 相机 / 相册权限请求卡（说明用途后请求）→ 授权后进入首页。（体现 PRD §5.3：开 App 时检查并申请。）

### 13. blueprint-lowconf.html — 解析低置信度
图纸区 + 温和提示「图纸不太清晰，建议重选一张 / 重新截图」+「重选图纸」按钮。**无手动框选工具**。

### 14. unsupported.html — 不支持场景
明确提示「这类图纸 / 拍摄场景暂不支持，建议换一张 / 重拍」+ 重选 / 重拍入口。**不出现手动逃生舱**。

### 15. detection-failed.html — 检测失败
「没认出来」+ 重拍 + 打光 / 角度建议（不强制手动校正）。

## 状态归属说明
- 选图纸的「解析中 / 成功 / 低置信度 / 不支持」：成功态在 `blueprint.html`（核心流详细）；低置信度、不支持各自单独一帧（边界简略）。解析中态在 `blueprint.html` 内以加载指示体现，不单独成帧。
- 结果的「有错 / 通过 / 检测失败」：有错、通过各一帧；检测失败单独一帧。
